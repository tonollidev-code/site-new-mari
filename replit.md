# Mari Nail Designer

## Project overview

This is a React + Vite website for Mari Nail Designer. It includes the studio landing page, service listings, portfolio gallery, booking flow, FAQ, location details, and an admin panel.

## Run locally

Install dependencies and start the development server:

```bash
npm install
npm run dev
```

The app is served on port 5000.

## Environment

Gemini-powered functionality requires the `GEMINI_API_KEY` secret. The public website and its static content do not require additional configuration.
